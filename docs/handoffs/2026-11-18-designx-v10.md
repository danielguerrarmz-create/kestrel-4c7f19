# DesignX Version 10

Version 10 publishes the reviewed presentation at `/designx/v10/`. It replaces slide 12 with the Dreaming Systems Loop layout and gives that slide its own index entry. Dreaming Systems incorporates Clay Seifert’s Trellis Loop stages alongside the Bower One geometry, costing and design review. The five views retain all 16 connections and the nine nodes can be expanded by pointer or keyboard.

The versioned entry point loads shared artwork and unchanged source scenes from `public/designx`. Revised scripts and styles live under `public/designx/v10`. The build derives the 1.5×-capable factory drawing pages from the original scenes for Version 10. Both default DesignX routes and the v8 entry point keep their published files.

## Verify

1. Run `npm run build` and `npm run preview -- --host 127.0.0.1 --port 5338 --strictPort`.
2. Open [Version 10 slide 12](http://127.0.0.1:5338/designx/v10/#slide-12), change views and expand a node. Press Escape or select the node again to collapse its caption.
3. Use the slide index and the Version 10 print link. Slide 12 prints as the whole-system diagram.
4. Open slide 5’s embedded explorer, a station on slide 7 and the manufacturing sequence on slide 8 to check that each versioned player loads.
5. Compare the existing `/designx` and `/designx/v8/` routes against the prior deployment.

## Files

- `public/designx/v10/` contains the versioned viewer, revised drawing controls and the Dreaming Systems slide.
- `scripts/designx/prepare-v10-factory.mjs` prepares the versioned drawing exports.
- `vercel.json` adds the two Version 10 route spellings.
